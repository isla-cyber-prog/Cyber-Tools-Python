# Password Breach Checker
- Checks whether a password appears within a list of common weak passwords.

## Cybersecurity Relevance
Weak passwords are one of the most common security weaknesses.

## Concepts Used
- Python
- Password Security
- Lists
- File Handling

## Features
- User enters password
- Compares against common password database
- Displays security warning if detected

## Example

Input:
password123

Output:
Warning: Password found in weak password database.
