# URL Analyser
-Breaks down a URL into its individual components.

## Cybersecurity Relevance
Attackers and defenders frequently analyse URLs when investigating phishing, malware, and web traffic.

## Concepts Used
- Python
- Web Technologies
- URL Parsing

## Features
- Displays scheme
- Displays domain
- Displays path

## Example

Input:
https://github.com/isla-cyber-prog

Output:
Scheme: https
Domain: github.com
Path: /isla-cyber-prog
