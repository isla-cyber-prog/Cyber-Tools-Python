# IP Address Validator
- Checks whether an IPv4 or IPv6 address entered by the user is valid.

## Cybersecurity Relevance
IP addresses are used to identify devices on networks and are fundamental to networking and cybersecurity.

## Concepts Used
- Python
- Input Validation
- Networking
- IPv4
- IPv6

## Features
- Validates IPv4 addresses
- Validates IPv6 addresses
- Displays whether an address is valid or invalid

## Example

Input:
192.168.1.1

Output:
Valid IPv4 Address
